# Claude-Code-Task-Board
G1. Giao việc (task) cho Claude Code qua một giao diện web. G2. Theo dõi trạng thái từng task: đang chờ, đang chạy, cần mình xử lý, chờ review, hoàn thành, lỗi. G3. Review kết quả (thay đổi code) và duyệt hoặc yêu cầu sửa ngay trên giao diện. G4. Quản lý toàn bộ công việc chỉ bằng giao diện, không cần mở VSCode để xem chi tiết.
